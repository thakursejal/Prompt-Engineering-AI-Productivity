# 🧪 Practical Experiments

The module includes practical experiments involving:

### Prompt Comparison

Comparing simple prompts with structured prompts to understand how additional context and constraints affect the expected output.

### Zero-Shot Prompting

Performing a task without providing examples.

### Few-Shot Prompting

Providing examples to guide the expected response.

### Structured Output

Generating information in a predefined JSON structure.

### AI-Assisted Debugging

Identifying and correcting programming errors with AI assistance.

### Prompt Evaluation

Testing different prompt versions using criteria such as:

- Relevance
- Accuracy
- Clarity
- Completeness
- Specificity
- Consistency
- Output format
